# Earth Pointer
This projects serves as a playground to build an airbone or celestial object tracker for a 2DOF camera unit.

## Opensky
The project uses opensky to  get sample aircraft data. To connect to their services you need to have a `secrets.json` at the root of the project structured like so :
``` json
{
    "clientId": "xxx",
    "clientSecret": "xxx"
}
```
## Getting sample data
Once setup, you can run `bun run scripts-scrap-aircrafts`.

## Finally
You can run `bun run dev` !

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
