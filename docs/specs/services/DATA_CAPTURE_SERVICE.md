# Data Capture Service Specification

## Overview

The `DataCaptureService` is a new service that logs aircraft tracking data to files for later analysis in Jupyter notebooks. It captures every prediction frame, the latest OpenSky data for each frame, and Kalman filter statistics, providing complete traceability of the tracking system's behavior.

## Purpose

This service enables:
- **Post-flight analysis**: Examine tracking accuracy and filter performance
- **3D visualization**: Create 3D plots of aircraft trajectories in Jupyter
- **Algorithm debugging**: Identify issues with Kalman filter tuning
- **Data audit**: Trace exactly what data was used for each prediction
- **Performance benchmarking**: Measure prediction accuracy over time

## Requirements

The service must:
1. Capture **every prediction frame** generated by the Kalman filter
2. Record the **latest OpenSky data** for the corresponding frame
3. Store **Kalman filter statistics** for each frame
4. Use a **format optimized for Jupyter notebooks** with 3D visualization
5. Support **efficient reading** of large capture files
6. Include **metadata** for proper data interpretation

---

## Design Decisions

### File Format Selection: HDF5

**Chosen Format: HDF5 (Hierarchical Data Format version 5)**

#### Why HDF5?

| Requirement | HDF5 | CSV | JSON | Parquet | SQLite |
|-------------|------|-----|------|--------|--------|
| 3D visualization support | Excellent | Good | Moderate | Good | Moderate |
| Efficient for large datasets | Excellent | Poor | Poor | Excellent | Good |
| Hierarchical structure | Yes | No | Yes | No | Yes (tables) |
| Metadata support | Yes | Limited | Yes | Limited | Yes |
| Fast random access | Yes | No | No | Yes | Yes |
| NumPy integration | Native | Manual | Manual | Good | Manual |
| Jupyter ecosystem | h5py, PyTables | pandas | pandas | pandas | sqlite3 |
| Compression support | Yes | No | No | Yes | Yes |
| Schema evolution | Yes | Difficult | Flexible | Limited | Moderate |

#### HDF5 Benefits for This Use Case:

1. **Native 3D array support**: Store positions as Nx3 arrays (lat, lon, alt)
2. **Hierarchical organization**: Group data by flight, time, or capture session
3. **Metadata storage**: Store capture parameters, filter settings, etc.
4. **Efficient I/O**: Fast reading of large datasets
5. **Compression**: Reduce file sizes with built-in compression
6. **NumPy compatibility**: Direct integration with `h5py` and `pandas`
7. **Matplotlib/Plotly support**: Both libraries work with HDF5 data
8. **Jupyter-friendly**: Can be read directly with `h5py` or `pandas.read_hdf()`

#### Alternative Considerations:

- **Parquet**: Good compression and pandas support, but less hierarchical
- **NetCDF**: Excellent for geospatial data, but less common in ML/visualization
- **Feather**: Fast pandas I/O, but less structured metadata

**Conclusion**: HDF5 provides the best combination of features for 3D visualization in Jupyter.

### Directory Structure

```
captures/
├── 2026-08-22/
│   ├── 14-30-00_session_001.h5
│   ├── 15-00-00_session_002.h5
│   └── 15-30-00_session_003.h5
└── 2026-08-23/
    └── 10-00-00_session_001.h5
```

### HDF5 File Structure

```
root/
├── metadata/
│   ├── capture_start: float (Unix timestamp)
│   ├── capture_end: float (Unix timestamp, updated on close)
│   ├── session_id: str (UUID)
│   ├── kalman_config: dict (filter parameters)
│   ├── location: dict (default location)
│   └── turret_version: str
├── frames/
│   ├── timestamps: 1D array[float] (Unix timestamps)
│   ├── frame_indices: 1D array[int] (sequential frame numbers)
│   └── predictions/
│       ├── callsigns: 1D array[str] (for each frame)
│       ├── count: 1D array[int] (number of predictions per frame)
│       └── <callsign>/
│           ├── positions: 2D array[N,3] (lat, lon, alt)
│           ├── velocities: 2D array[N,3] (v_north, v_east, v_alt)
│           ├── covariates: 2D array[N,3] (cov_lat, cov_lon, cov_alt)
│           ├── headings: 1D array[float] (true_track)
│           ├── speeds: 1D array[float] (velocity)
│           ├── states: 1D array[str] (filter state)
│           └── timestamps: 1D array[float]
└── opensky/
    ├── timestamps: 1D array[float]
    └── <callsign>/
        ├── positions: 2D array[N,3]
        ├── velocities: 2D array[N,3]
        ├── baro_altitudes: 1D array[float]
        ├── on_ground: 1D array[bool]
        └── timestamps: 1D array[float]
└── statistics/
    ├── timestamps: 1D array[float]
    ├── track_count: 1D array[int]
    ├── prediction_count: 1D array[int]
    ├── total_predictions: 1D array[int]
    ├── total_measurements: 1D array[int]
    ├── data_update_interval: 1D array[float]
    └── prediction_interval: 1D array[float]
```

## Data Capture Specification

### Capture Frame Definition

A **capture frame** is a single point-in-time snapshot containing:
1. All predictions generated at that time
2. The latest OpenSky data available at that time
3. The Kalman filter statistics at that time

### Frame Rate

- **Prediction frames**: Captured every 500ms (matches `PREDICTION_INTERVAL`)
- **OpenSky data frames**: Captured every 10s (matches `DATA_UPDATE_INTERVAL`)
- **Statistics frames**: Captured every 500ms

### Data Retention

- **Prediction data**: All frames retained
- **OpenSky data**: Latest data for each frame retained
- **Statistics**: Every frame retained

## Service Class Design

### DataCaptureService Class

```python
from dataclasses import dataclass, asdict
from typing import Dict, List, Optional
import h5py
import numpy as np
import time
import threading
import os
import uuid
from datetime import datetime
from pathlib import Path

from services.kalman_filter_service import kalman_filter_service
from services.aircraft_service import aircraft_service
from utils.logger import get_logger


class DataCaptureService:
    """
    Service for capturing aircraft tracking data to HDF5 files.
    
    Captures:
    - Every prediction frame
    - Latest OpenSky data for each frame
    - Kalman filter statistics
    
    Output format: HDF5 (optimized for Jupyter 3D visualization)
    """
    
    # Configuration
    CAPTURE_DIR = "captures"  # Relative to server directory
    SESSION_DURATION = 3600.0  # 1 hour sessions (seconds)
    MAX_FILE_SIZE = 1024 * 1024 * 1024  # 1 GB per file
    COMPRESSION_LEVEL = 4  # HDF5 compression (0-9)
    
    def __init__(self, kalman_service=None, aircraft_service_ref=None):
        self.kalman_service = kalman_service or kalman_filter_service
        self.aircraft_service = aircraft_service_ref or aircraft_service
        self.logger = get_logger("CAPTURE")
        
        # State
        self._current_file: Optional[h5py.File] = None
        self._current_session_id: Optional[str] = None
        self._current_file_path: Optional[str] = None
        self._frame_count = 0
        self._start_time = 0.0
        
        # Threading
        self._lock = threading.Lock()
        self._shutdown_flag = threading.Event()
        self._capture_thread: Optional[threading.Thread] = None
        
        # Statistics
        self._frames_captured = 0
        self._last_capture_time = 0.0
    
    def start(self):
        """Start the capture service."""
        self._start_new_session()
        
        # Start background capture thread
        self._shutdown_flag.clear()
        self._capture_thread = threading.Thread(
            target=self._capture_loop,
            daemon=True,
            name="data-capture"
        )
        self._capture_thread.start()
        self.logger.info("Data capture service started")
    
    def stop(self):
        """Stop the capture service and close current file."""
        self._shutdown_flag.set()
        
        if self._capture_thread and self._capture_thread.is_alive():
            self._capture_thread.join(timeout=2.0)
        
        self._close_current_file()
        self.logger.info("Data capture service stopped")
    
    def _start_new_session(self):
        """Start a new capture session with a new HDF5 file."""
        with self._lock:
            self._close_current_file()
            
            # Create capture directory if needed
            Path(self.CAPTURE_DIR).mkdir(parents=True, exist_ok=True)
            
            # Generate session ID and filename
            self._current_session_id = str(uuid.uuid4())
            timestamp = datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
            filename = f"{timestamp}_session_{self._frame_count:04d}.h5"
            
            # Create date subdirectory
            date_dir = Path(self.CAPTURE_DIR) / datetime.now().strftime("%Y-%m-%d")
            date_dir.mkdir(parents=True, exist_ok=True)
            
            self._current_file_path = str(date_dir / filename)
            
            # Open new HDF5 file
            self._current_file = h5py.File(self._current_file_path, 'w')
            self._frame_count = 0
            self._start_time = time.time()
            
            # Write metadata
            self._write_metadata()
            
            self.logger.info(f"Started new capture session: {self._current_file_path}")
    
    def _write_metadata(self):
        """Write capture metadata to the HDF5 file."""
        if self._current_file is None:
            return
        
        # Get Kalman filter configuration
        kalman_config = {
            'data_update_interval': self.kalman_service.DATA_UPDATE_INTERVAL,
            'prediction_interval': self.kalman_service.PREDICTION_INTERVAL,
            'max_measurement_age': self.kalman_service.MAX_MEASUREMENT_AGE,
            'position_process_noise': self.kalman_service.POSITION_PROCESS_NOISE,
            'velocity_process_noise': self.kalman_service.VELOCITY_PROCESS_NOISE,
            'position_measurement_noise': self.kalman_service.POSITION_MEASUREMENT_NOISE,
        }
        
        # Get default location
        default_location = self.aircraft_service.last_position
        
        # Write metadata
        metadata_group = self._current_file.create_group('metadata')
        metadata_group.attrs['capture_start'] = self._start_time
        metadata_group.attrs['session_id'] = self._current_session_id
        metadata_group.attrs['kalman_config'] = np.void(
            str(json.dumps(kalman_config)).encode('utf-8')
        )
        metadata_group.attrs['location'] = np.void(
            str(json.dumps(default_location)).encode('utf-8')
        )
        metadata_group.attrs['turret_version'] = '1.0.0'
        metadata_group.attrs['file_format_version'] = '1.0'
    
    def _close_current_file(self):
        """Close the current HDF5 file if open."""
        if self._current_file is not None:
            try:
                # Update capture_end time
                if 'metadata' in self._current_file:
                    self._current_file['metadata'].attrs['capture_end'] = time.time()
                
                self._current_file.close()
                self.logger.info(f"Closed capture file: {self._current_file_path}")
            except Exception as e:
                self.logger.error(f"Error closing HDF5 file: {e}")
            finally:
                self._current_file = None
                self._current_file_path = None
    
    def _capture_loop(self):
        """Background thread that captures data periodically."""
        self.logger.info("Starting capture loop...")
        
        while not self._shutdown_flag.is_set():
            start_time = time.time()
            
            try:
                # Capture current frame
                self.capture_frame()
                self._frames_captured += 1
                self._last_capture_time = start_time
                
            except Exception as e:
                self.logger.error(f"Error in capture loop: {e}")
            
            # Check if we need to start a new session
            if self._should_start_new_session():
                self._start_new_session()
            
            # Sleep for prediction interval
            elapsed = time.time() - start_time
            sleep_time = max(0, self.kalman_service.PREDICTION_INTERVAL - elapsed)
            
            # Sleep with periodic shutdown checks
            sleep_start = time.time()
            while (not self._shutdown_flag.is_set() and 
                   (time.time() - sleep_start) < sleep_time):
                time.sleep(0.001)
    
    def _should_start_new_session(self) -> bool:
        """Check if a new capture session should be started."""
        # Start new session every hour
        if time.time() - self._start_time > self.SESSION_DURATION:
            return True
        
        # Check file size
        if self._current_file_path and os.path.exists(self._current_file_path):
            file_size = os.path.getsize(self._current_file_path)
            if file_size > self.MAX_FILE_SIZE:
                return True
        
        return False
    
    def capture_frame(self):
        """
        Capture a single frame of data.
        
        A frame includes:
        - All current predictions
        - Latest OpenSky data
        - Current Kalman statistics
        """
        if self._current_file is None:
            self._start_new_session()
        
        with self._lock:
            current_time = time.time()
            frame_index = self._frame_count
            self._frame_count += 1
            
            # Get predictions
            predictions = self.kalman_service.get_latest_predictions()
            
            # Get latest flight data
            flight_data = self.kalman_service._latest_flight_data
            
            # Get statistics
            statistics = self.kalman_service.get_statistics()
            
            # Write to HDF5
            self._write_frame(frame_index, current_time, predictions, flight_data, statistics)
    
    def _write_frame(self, frame_index: int, timestamp: float, 
                    predictions: List[Dict], flight_data: Dict[str, Dict],
                    statistics: Dict):
        """Write a frame of data to the HDF5 file."""
        if self._current_file is None:
            return
        
        # Create or extend datasets for frames
        self._ensure_frame_datasets()
        
        # Write frame metadata
        self._current_file['frames/timestamps'][frame_index] = timestamp
        self._current_file['frames/frame_indices'][frame_index] = frame_index
        
        # Write predictions
        self._write_predictions(frame_index, timestamp, predictions)
        
        # Write OpenSky data
        self._write_opensky_data(frame_index, timestamp, flight_data)
        
        # Write statistics
        self._write_statistics(frame_index, timestamp, statistics)
    
    def _ensure_frame_datasets(self):
        """Ensure frame-level datasets exist and are resizable."""
        if 'frames' not in self._current_file:
            frames_group = self._current_file.create_group('frames')
            
            # Create resizable datasets
            maxshape = (None,)  # Unlimited in first dimension
            
            frames_group.create_dataset(
                'timestamps',
                data=np.zeros(0, dtype=np.float64),
                maxshape=maxshape,
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            frames_group.create_dataset(
                'frame_indices',
                data=np.zeros(0, dtype=np.int64),
                maxshape=maxshape,
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            
            # Create predictions group
            predictions_group = frames_group.create_group('predictions')
            predictions_group.create_dataset(
                'callsigns',
                data=np.zeros(0, dtype='S10'),  # Fixed-length strings
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            predictions_group.create_dataset(
                'count',
                data=np.zeros(0, dtype=np.int32),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
    
    def _write_predictions(self, frame_index: int, timestamp: float, 
                          predictions: List[Dict]):
        """Write prediction data for a frame."""
        if self._current_file is None or len(predictions) == 0:
            return
        
        # Extract callsigns
        callsigns = [p['callsign'] for p in predictions]
        
        # Write to callsigns and count datasets
        self._current_file['frames/predictions/callsigns'].resize(
            (frame_index + 1,) + self._current_file['frames/predictions/callsigns'].shape
        )
        self._current_file['frames/predictions/count'].resize(
            (frame_index + 1,) + self._current_file['frames/predictions/count'].shape
        )
        
        # Store callsigns as comma-separated string for this frame
        # (HDF5 doesn't handle variable-length arrays well)
        self._current_file['frames/predictions/callsigns'][frame_index] = np.string_(','.join(callsigns))
        self._current_file['frames/predictions/count'][frame_index] = len(predictions)
        
        # Create per-flight groups and datasets
        for pred in predictions:
            callsign = pred['callsign']
            
            # Create flight group if it doesn't exist
            flight_path = f'frames/predictions/{callsign}'
            if flight_path not in self._current_file:
                flight_group = self._current_file.create_group(flight_path)
                
                # Create datasets for this flight
                maxshape = (None,)  # Unlimited
                flight_group.create_dataset(
                    'positions',
                    data=np.zeros((0, 3), dtype=np.float64),
                    maxshape=(None, 3),
                    chunks=(100, 3),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'velocities',
                    data=np.zeros((0, 3), dtype=np.float64),
                    maxshape=(None, 3),
                    chunks=(100, 3),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'covariances',
                    data=np.zeros((0, 3), dtype=np.float64),
                    maxshape=(None, 3),
                    chunks=(100, 3),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'headings',
                    data=np.zeros(0, dtype=np.float64),
                    maxshape=maxshape,
                    chunks=(100,),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'speeds',
                    data=np.zeros(0, dtype=np.float64),
                    maxshape=maxshape,
                    chunks=(100,),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'states',
                    data=np.zeros(0, dtype='S20'),
                    maxshape=maxshape,
                    chunks=(100,),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'timestamps',
                    data=np.zeros(0, dtype=np.float64),
                    maxshape=maxshape,
                    chunks=(100,),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
            
            # Append data for this flight
            flight_group = self._current_file[flight_path]
            
            # Resize datasets
            current_size = flight_group['positions'].shape[0]
            new_size = current_size + 1
            
            flight_group['positions'].resize((new_size, 3))
            flight_group['velocities'].resize((new_size, 3))
            flight_group['covariances'].resize((new_size, 3))
            flight_group['headings'].resize((new_size,))
            flight_group['speeds'].resize((new_size,))
            flight_group['states'].resize((new_size,))
            flight_group['timestamps'].resize((new_size,))
            
            # Write data
            flight_group['positions'][current_size] = [
                pred['latitude'],
                pred['longitude'],
                pred['baro_altitude']
            ]
            
            # Convert velocity and heading to components
            velocity = pred['velocity']
            true_track = pred['true_track']
            v_north = velocity * np.cos(np.radians(true_track))
            v_east = velocity * np.sin(np.radians(true_track))
            v_alt = pred['vertical_rate']
            
            flight_group['velocities'][current_size] = [v_north, v_east, v_alt]
            flight_group['covariances'][current_size] = [
                pred['covariance_lat'],
                pred['covariance_lon'],
                pred['covariance_alt']
            ]
            flight_group['headings'][current_size] = true_track
            flight_group['speeds'][current_size] = velocity
            flight_group['states'][current_size] = np.string_(pred['state'])
            flight_group['timestamps'][current_size] = timestamp
    
    def _write_opensky_data(self, frame_index: int, timestamp: float, 
                           flight_data: Dict[str, Dict]):
        """Write OpenSky data for a frame."""
        if self._current_file is None or len(flight_data) == 0:
            return
        
        # Create opensky group if it doesn't exist
        if 'opensky' not in self._current_file:
            opensky_group = self._current_file.create_group('opensky')
            opensky_group.create_dataset(
                'timestamps',
                data=np.zeros(0, dtype=np.float64),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
        
        # Store all OpenSky data for this frame
        opensky_group = self._current_file['opensky']
        
        # Resize timestamps
        current_size = opensky_group['timestamps'].shape[0]
        opensky_group['timestamps'].resize((current_size + 1,))
        opensky_group['timestamps'][current_size] = timestamp
        
        # Store flight data
        for callsign, data in flight_data.items():
            # Create flight group if it doesn't exist
            flight_path = f'opensky/{callsign}'
            if flight_path not in self._current_file:
                flight_group = self._current_file.create_group(flight_path)
                flight_group.create_dataset(
                    'positions',
                    data=np.zeros((0, 3), dtype=np.float64),
                    maxshape=(None, 3),
                    chunks=(100, 3),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'velocities',
                    data=np.zeros((0, 3), dtype=np.float64),
                    maxshape=(None, 3),
                    chunks=(100, 3),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'baro_altitudes',
                    data=np.zeros(0, dtype=np.float64),
                    maxshape=(None,),
                    chunks=(100,),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'on_ground',
                    data=np.zeros(0, dtype=np.bool_),
                    maxshape=(None,),
                    chunks=(100,),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
                flight_group.create_dataset(
                    'timestamps',
                    data=np.zeros(0, dtype=np.float64),
                    maxshape=(None,),
                    chunks=(100,),
                    compression='gzip',
                    compression_opts=self.COMPRESSION_LEVEL
                )
            
            flight_group = self._current_file[flight_path]
            current_size = flight_group['positions'].shape[0]
            new_size = current_size + 1
            
            # Resize datasets
            flight_group['positions'].resize((new_size, 3))
            flight_group['velocities'].resize((new_size, 3))
            flight_group['baro_altitudes'].resize((new_size,))
            flight_group['on_ground'].resize((new_size,))
            flight_group['timestamps'].resize((new_size,))
            
            # Extract data
            lat = data.get('latitude', 0.0)
            lon = data.get('longitude', 0.0)
            alt = data.get('baro_altitude', 0.0)
            velocity = data.get('velocity', 0.0)
            true_track = data.get('true_track', 0.0)
            on_ground = data.get('on_ground', True)
            
            # Convert velocity to components
            v_north = velocity * np.cos(np.radians(true_track))
            v_east = velocity * np.sin(np.radians(true_track))
            v_alt = data.get('vertical_rate', 0.0)
            
            # Write data
            flight_group['positions'][current_size] = [lat, lon, alt]
            flight_group['velocities'][current_size] = [v_north, v_east, v_alt]
            flight_group['baro_altitudes'][current_size] = alt
            flight_group['on_ground'][current_size] = on_ground
            flight_group['timestamps'][current_size] = timestamp
    
    def _write_statistics(self, frame_index: int, timestamp: float, 
                         statistics: Dict):
        """Write Kalman filter statistics for a frame."""
        if self._current_file is None:
            return
        
        # Create statistics group if it doesn't exist
        if 'statistics' not in self._current_file:
            stats_group = self._current_file.create_group('statistics')
            stats_group.create_dataset(
                'timestamps',
                data=np.zeros(0, dtype=np.float64),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            stats_group.create_dataset(
                'track_count',
                data=np.zeros(0, dtype=np.int32),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            stats_group.create_dataset(
                'prediction_count',
                data=np.zeros(0, dtype=np.int32),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            stats_group.create_dataset(
                'total_predictions',
                data=np.zeros(0, dtype=np.int64),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            stats_group.create_dataset(
                'total_measurements',
                data=np.zeros(0, dtype=np.int64),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            stats_group.create_dataset(
                'data_update_interval',
                data=np.zeros(0, dtype=np.float64),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
            stats_group.create_dataset(
                'prediction_interval',
                data=np.zeros(0, dtype=np.float64),
                maxshape=(None,),
                chunks=(100,),
                compression='gzip',
                compression_opts=self.COMPRESSION_LEVEL
            )
        
        stats_group = self._current_file['statistics']
        current_size = stats_group['timestamps'].shape[0]
        new_size = current_size + 1
        
        # Resize datasets
        stats_group['timestamps'].resize((new_size,))
        stats_group['track_count'].resize((new_size,))
        stats_group['prediction_count'].resize((new_size,))
        stats_group['total_predictions'].resize((new_size,))
        stats_group['total_measurements'].resize((new_size,))
        stats_group['data_update_interval'].resize((new_size,))
        stats_group['prediction_interval'].resize((new_size,))
        
        # Write data
        stats_group['timestamps'][current_size] = timestamp
        stats_group['track_count'][current_size] = statistics['track_count']
        stats_group['prediction_count'][current_size] = statistics['prediction_count']
        stats_group['total_predictions'][current_size] = statistics['total_predictions']
        stats_group['total_measurements'][current_size] = statistics['total_measurements']
        stats_group['data_update_interval'][current_size] = statistics['data_update_interval']
        stats_group['prediction_interval'][current_size] = statistics['prediction_interval']
    
    def get_status(self) -> Dict:
        """Get the current status of the capture service."""
        return {
            "is_capturing": self._capture_thread is not None and self._capture_thread.is_alive(),
            "frames_captured": self._frames_captured,
            "current_file": self._current_file_path,
            "session_id": self._current_session_id,
            "last_capture_time": self._last_capture_time,
            "capture_start_time": self._start_time,
            "elapsed_time": time.time() - self._start_time if self._start_time > 0 else 0
        }
    
    def get_capture_files(self) -> List[str]:
        """Get a list of all capture files."""
        capture_dir = Path(self.CAPTURE_DIR)
        if not capture_dir.exists():
            return []
        
        files = []
        for h5_file in capture_dir.rglob('*.h5'):
            files.append(str(h5_file))
        
        return sorted(files, reverse=True)
```

## File Management

### Session Rotation

The service automatically rotates to a new file based on:
1. **Time-based rotation**: Every `SESSION_DURATION` seconds (default: 1 hour)
2. **Size-based rotation**: When file exceeds `MAX_FILE_SIZE` (default: 1GB)

### File Naming Convention

Files are named using the pattern:
```
{YYYY}-{MM}-{DD}/{HH}-{MM}-{SS}_session_{NNNN}.h5
```

Where:
- `{YYYY}-{MM}-{DD}`: Date directory
- `{HH}-{MM}-{SS}`: Start time of capture session
- `{NNNN}`: Sequential session number (4 digits)
- `.h5`: HDF5 file extension

## Performance Considerations

### HDF5 Performance Tips

1. **Chunking**: Use appropriate chunk sizes for datasets
2. **Compression**: GZIP compression level 4 provides good balance
3. **Resizing**: Resize datasets in chunks rather than one element at a time
4. **Batching**: Consider batching writes for high-frequency captures

### Memory Usage

- Each frame stores:
  - Predictions: ~100 bytes per aircraft
  - OpenSky data: ~100 bytes per aircraft
  - Statistics: ~50 bytes
- For 10 aircraft at 2 frames/second: ~4 KB/second
- For 1 hour session: ~14 MB

### Disk Usage

- With compression: ~50% of uncompressed size
- 1 hour session with 10 aircraft: ~7 MB compressed
- 1 hour session with 50 aircraft: ~35 MB compressed

---

## Error Handling

The service handles errors gracefully:
- **HDF5 errors**: Logged and service continues
- **File system errors**: Retry with new session
- **Thread errors**: Caught and logged, thread continues
- **Missing data**: Empty frames are logged but not failed

```python
    sigma_lon = np.sqrt(covariances[:, 1])

    sigma_horiz = np.sqrt(sigma_lat**2 + sigma_lon**2)

    time_relative = data['timestamps'] - data['timestamps'][0]
    
    plt.plot(time_relative, sigma_horiz, label='Horizontal', color='blue')
    plt.plot(time_relative, sigma_alt, label='Vertical', color='red')
```
